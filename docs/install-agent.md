# Agent-assisted installation

Use the same signed archives and README commands as independent installation. The agent is a presenter/preparer; the gateway remains pure MCP and runs no model, watcher or task scheduler.

1. Inspect platform/architecture, installed prefix and port read-only. Choose the matching signed asset and frozen release. Never choose a new source silently.
2. Present the exact README commands for that platform (or the release-notes variant that pins the exact source commit), locations and expected result. Bootstrap trust comes from the SHA-256 pinned in the independently authenticated README, not from a package page alone. Installation needs an administrator account.
3. Hand off system approval and secret entry to the owner's ordinary terminal. Stop agents/capture during credentials. Do not use UI automation, clipboard or screenshots to handle secrets; never ask for a signing key.
4. Resume from actual protected receipt/service and safe wizard results. A chat message or UUID is not authority. Preserve valid completed state.
5. Distinguish installed service, listener ownership, authenticated SDK connectivity, selected profile configuration, client restart and actual model tool loading. Verify reads first. Any live write needs a separate controlled preview and consent.

Suggested request: "Prepare this platform's README installation steps from the approved signed release. Do not install elevated or handle credentials. Show the expected results and hand off the human terminal steps, then help interpret safe verification results."
